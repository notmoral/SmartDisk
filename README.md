# SmartDisk

Инструмент для анализа и очистки дискового пространства. Проект создан для решения проблемы захламления файловой системы: программа быстро находит дубликаты, тяжелые файлы и пустые директории, а также предоставляет современный интерфейс для управления ими.

## Основные возможности

*   **Поиск дубликатов.** Используется каскадный алгоритм: сначала файлы группируются по размеру, затем сравниваются первые 4 КБ, и только при совпадении выполняется полное хэширование. Это позволяет отсеивать ложные совпадения и экономить ресурсы.
*   **Анализ больших файлов.** Выявление топ-50 файлов, занимающих наибольший объем на диске.
*   **Поиск пустых папок.** Обнаружение директорий, не содержащих файлов, с возможностью их удаления.
*   **Визуальная статистика.** Построение интерактивных диаграмм распределения места по типам файлов (с возможностью переключения между объемом и количеством).
*   **Массовое управление.** Выделение группы файлов чекбоксами для одновременного удаления.
*   **Интерфейс.** Поддержка светлой и темной тем с плавной анимацией переключения.

## Технический стек

Изначально прототип был реализован на чистом Python, однако для обеспечения высокой скорости работы ядро было переписано на **Rust**.

*   **Rust (PyO3, Rayon, XXH3, Jwalk)** — высокопроизводительное ядро для параллельного обхода файловой системы и быстрого хэширования.
*   **Python** — серверная логика и связующее звено между ядром и интерфейсом.
*   **PyWebView (HTML/CSS/JS, Chart.js)** — графический интерфейс, выполненный в стиле Glassmorphism (эффект матового стекла, градиенты, прозрачность).

## Инструкция по локальному запуску

Для работы требуются установленные Python (3.10+) и Rust (Cargo).

**Клонирование репозитория:**
```bash
git clone https://github.com/notmoral/SmartDisk.git
cd SmartDisk
Настройка виртуального окружения и зависимостей:

bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
pip install maturin
Сборка нативного ядра (Rust):
Примечание: флаг PYO3_USE_ABI3_FORWARD_COMPATIBILITY необходим для совместимости с новыми версиями Python (например, 3.14).

bash
cd rust_core
set PYO3_USE_ABI3_FORWARD_COMPATIBILITY=1
maturin develop --release
cd ..
Запуск приложения:

bash
venv\Scripts\python.exe main.py
